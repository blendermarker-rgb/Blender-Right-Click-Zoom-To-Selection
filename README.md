# Blender Right Click Zoom To Selection

A small Blender add-on that adds **Zoom To Selection** to the right-click menu in the 3D View.

I originally created this because I was used to having quick access to this type of command in SketchUp. I use it regularly in Blender and thought other Blender users might find it useful too.

## What It Does

Select an object or mesh element, right-click, and choose:

**Zoom To Selection**

Blender will frame the current selection in the 3D View.

The command is available in:

- Object Mode
- Edit Mode

## Installation

### Blender 4.5

1. Download `right_click_zoom.py`.
2. Open Blender.
3. Go to **Edit > Preferences**.
4. Select **Add-ons**.
5. Open the menu in the upper-right corner.
6. Choose **Install from Disk**.
7. Select `right_click_zoom.py`.
8. Enable **Zoom To Selection** if it is not already enabled.

## How To Use

1. Select an object in Object Mode, or select vertices, edges, or faces in Edit Mode.
2. Right-click in the 3D View.
3. Choose **Zoom To Selection**.
